# Future Features

These ideas are explicitly out of scope for version 1.
They are documented here to avoid feature creep during the MVP build.

Do not implement any of these in version 1.

## Gesture Extensions
- Custom gesture mapping (user-defined gestures)
- Volume control gesture (e.g. palm push up/down)
- Next video / previous video gestures
- Seek forward / backward gestures
- Fullscreen toggle gesture
- Finger count gestures (e.g. 2 fingers = next)

## Platform Support
- Spotify control
- Netflix control
- Apple Music control
- VLC media player control
- Presentation control (PowerPoint, Google Slides)
- General media key support

## Multi-Camera
- Multiple camera support
- Camera selection UI
- Camera preview window

## Application Settings
- GUI settings panel (instead of config.yaml only)
- User profiles with saved gesture preferences
- Gesture training / calibration wizard
- Per-application gesture profiles

## Account & Cloud
- User accounts
- Cloud synchronization of settings
- Usage analytics (opt-in only)

## Platform Expansion
- macOS support
- Linux support

## Advanced Hand Tracking
- Two-hand gestures
- Pinch gestures
- Wave gestures
- Thumbs up / thumbs down gestures

## Installation
- Chrome Web Store publication (remove Developer Mode requirement)
- Edge Add-ons store publication
- Windows installer (NSIS / Inno Setup)
- Auto-update mechanism
